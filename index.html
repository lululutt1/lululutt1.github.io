MY CONTRIBUTIONS

Systems I Worked On

Explore some of the systems I implemented and contributed to during development.

SYSTEM 01 / 04

Collectible System

Implemented a collectible system that allows players to interact with story-related items throughout the level.

My Implementation

  • Used Unity's trigger system to detect player interactions.
  • Connected collectible interactions to the narrative UI.
  • Updated the game state when an item was collected.
  • Removed the collectible after successful interaction.

How It Works

When the player enters the collectible's trigger area, a narrative dialogue appears. The game state is updated, and the collectible disappears.

SYSTEM 02 / 04

Dialogue System

Developed the dialogue interaction system to display story conversations during gameplay.

My Implementation

  • Read dialogue entries from CSV data.
  • Displayed dialogue through a UI dialogue box.
  • Allowed players to advance dialogue by pressing E.
  • Managed the progression between dialogue lines.

How It Works

Dialogue data is loaded and displayed in the UI. Players press E to move through the conversation one line at a time.

SYSTEM 03 / 04

Narrative Progression

Connected collectible interactions and dialogue events to support the game's narrative progression.

My Implementation

  • Triggered narrative events through collectibles.
  • Connected the dialogue system with story interactions.
  • Used game state information to track progression.

How It Works

Players discover story-related items while exploring the level. Collecting them triggers dialogue and reveals parts of the narrative.

SYSTEM 04 / 04

Door & Level Progression

Implemented door interaction logic that checks whether the player has collected the required item before moving to the next level.

My Implementation

  • Checked the collectible state when the player reached the door.
  • Allowed level progression when the requirement was met.
  • Displayed dialogue when the player had not collected the item.

How It Works

The door checks the player's progress. If the required collectible has been obtained, the next scene loads. Otherwise, the player receives a dialogue prompt.
